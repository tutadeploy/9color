# 9Color 数据库备份系统完整说明

## 📊 数据库备份系统概览

### 🏗️ 备份架构

该系统采用**三层备份策略**：
1. **完整备份** - 每日凌晨2点执行
2. **增量备份** - 每小时执行（二进制日志）
3. **健康监控** - 实时数据库状态检查

### 🔧 备份服务配置

#### Docker Compose 备份服务
```yaml
mysql-backup:
  image: mysql:5.7
  container_name: 9color_mysql_backup
  volumes:
    - mysql_backup:/var/backups
    - ./backup:/backup
    - ./scripts:/scripts
  environment:
    MYSQL_HOST: mysql
    MYSQL_ROOT_PASSWORD: root123456
    MYSQL_DATABASE: 6ui
```

#### 备份调度器 (`backup-scheduler.sh`)
- **运行模式**: 持续运行的守护进程
- **检查间隔**: 每60秒检查一次时间
- **日志记录**: 所有操作记录到 `/backup/backup.log`

### 📅 备份时间表

| 备份类型 | 执行时间 | 频率 | 保留期 |
|---------|---------|------|--------|
| **完整备份** | 每日 02:00 | 每天1次 | 5天 |
| **增量备份** | 每小时 :00分 | 每小时1次 | 2天 |
| **健康检查** | 备份时同步执行 | 跟随备份 | - |

### 💾 备份内容详情

#### 完整备份包含：
- ✅ 数据库结构 (CREATE TABLE)
- ✅ 所有数据 (INSERT)
- ✅ 存储过程 (--routines)
- ✅ 触发器 (--triggers)
- ✅ 事件调度器 (--events)
- ✅ 二进制日志位置 (--master-data=2)
- ✅ 自动压缩 (.gz)

#### 增量备份包含：
- ✅ 二进制日志文件 (mysql-bin.*)
- ✅ 事务级别的变更记录
- ✅ 可用于时间点恢复

### 📁 备份目录结构

```
backup/
├── daily/          # 完整备份存储
│   └── 6ui_full_YYYYMMDD_HHMMSS.sql.gz
├── hourly/         # 增量备份存储（预留）
├── binlog/         # 二进制日志备份
│   └── mysql-bin.*
└── backup.log      # 备份操作日志
```

### 🔍 健康监控指标

备份系统会自动监控以下指标：

1. **数据库连接状态** - 确保服务可用
2. **数据库大小** - 监控存储空间使用
3. **慢查询统计** - 性能监控
4. **当前连接数** - 负载监控

### 💡 空间优化策略

考虑到40GB磁盘限制：
- **完整备份**: 保留5天（适中的恢复窗口）
- **增量备份**: 保留2天（快速恢复）
- **自动压缩**: 完整备份使用gzip压缩
- **自动清理**: 过期文件自动删除

## 🛠️ 手动操作指南

### 手动备份命令

#### 立即完整备份：
```bash
docker exec 9color_mysql_standalone mysqldump \
  -u root -proot123456 \
  --single-transaction --routines --triggers --events \
  6ui > backup_$(date +%Y%m%d).sql
```

#### 恢复备份：
```bash
docker exec -i 9color_mysql_standalone mysql \
  -u root -proot123456 6ui < backup_20241201.sql
```

## 📋 备份调度器详细配置

### 脚本功能说明

`backup-scheduler.sh` 脚本包含以下主要功能：

#### 1. 完整备份函数 (`full_backup`)
```bash
mysqldump \
    -h "$DB_HOST" \
    -P "$DB_PORT" \
    -u root \
    -p"$DB_PASS" \
    --single-transaction \
    --routines \
    --triggers \
    --events \
    --master-data=2 \
    --flush-logs \
    --opt \
    "$DB_NAME" >"$backup_file"
```

#### 2. 增量备份函数 (`incremental_backup`)
- 刷新二进制日志：`FLUSH LOGS`
- 复制二进制日志文件到备份目录
- 自动清理过期的二进制日志

#### 3. 健康检查函数 (`health_check`)
- 数据库连接测试
- 数据库大小统计
- 慢查询计数
- 当前连接数统计

### 配置变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `DB_HOST` | mysql | 数据库主机名 |
| `DB_PORT` | 3306 | 数据库端口 |
| `DB_USER` | backup | 备份用户名 |
| `DB_PASS` | root123456 | 数据库密码 |
| `DB_NAME` | 6ui | 数据库名称 |
| `BACKUP_DIR` | /backup | 备份根目录 |
